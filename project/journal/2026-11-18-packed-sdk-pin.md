> Written by: Codex

> **State** · locally qualified, 2026-11-18. ONE-FORMAT OF-EM28d.

The SDK release supplies the packed Int16 lane writer and exact
vertex welding used by Nine's slab generator. The author project
uses the published 0.1.42 engine reader and SDK 0.4.9. Map input
declarations follow the writer's packaged portable math module. The
author-only inventory and raster imports use the SDK dev exports.
Engine 0.1.42's lint layer list predates that package, so those exact
imports carry a layer-rule annotation.

The published pins typecheck and build the Nine product. The native
geometry is the five-slab candidate from the alternating memory
proof. It retains 704,230 triangles and lowered the WebKit control
buffer ledger from 110.67 to 84.83 MB. The MacBook release slot owns
the production cook and engine product pin.
