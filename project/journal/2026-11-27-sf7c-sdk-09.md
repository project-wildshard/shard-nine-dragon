# SF7c pre-stage on SDK 0.9.0

Nine rides the second train (engine 0.1.100-next, format 0.82.4, an SDK
patch on 0.9.0), so the pre-stage moved from 0.8.1 to a local 0.9.0 copy
with engine main and format main linked (J475). `wildshard migrate` ran
0.9.0: `src/shard.json` declares shardVersion 0.0.12.

Two refusals on the way. The GLB bake refused "textures" Nine never set:
the linked SDK resolved its own copy of three, so `instanceof` failed;
fixed in the SDK (it reads three's flags now). Then the standalone-art
check refused `baked/navmesh.bin`, the platform's navigation URL, which
Nine served but never listed in `mounts.json` (Driftwood, Far Reach and
Pine list theirs). It is listed now; the bytes are the same as the
authored navigation input. `wildshard check src` passes at 80.46 MB.
