# SF25: pin SDK 0.9.3 and format 0.82.8

Nine's images-only upload 0.0.12 was refused at 1,837,902,579 B worst
loading, over the 1.5 GB phone line. Format 0.82.4 charged the images
the cook mounts at boot as decoded RGBA. Format 0.82.8 charges every
image the cook encodes at its cooked KTX2 size and puts Nine at about
1.19 GB. The API took 0.82.8 in v0.40.5. The re-publish (run
46042289604) was then refused by sharddev's own pre-upload check, which
still ran format 0.82.4, so every @wildshard package moves to 0.9.3
exactly. The overrides name format 0.82.8, kit and upload 0.9.3, and the
unchanged engine 0.1.100-next.922b9d45.
