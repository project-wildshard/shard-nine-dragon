# Read Nine’s online loading peak in CI

> Written by: Codex
>
> **State:** MG2, 2026-11-19.

SDK 0.4.17 runs the published preparation client with a local Node world and
proves that the browser reaches control online without a server worker. Nine
installs the Chromium shell resolved by its pinned engine and runs the SDK
meter on the Ring 2 product. Keep its byte readings and verdict with the CI21
artifacts. The standard CLI compares the loading renderer peak at EM11’s
factor with the 1.5 GB phone line.

The engine pin is 0.1.50 and the format pin is 0.48.0. The restored scroll
textures from `8486d0d` are in the built mounts. Mossgate is the under-line
control from the release source. It reached control online at 716 MB in
sharddev CI. [Mossgate proof](https://github.com/project-wildshard/sharddev/actions/runs/44570100199/job/135725006166).

The published SDK build and author check passed locally. The matching client
booted Nine online on the Mac with a 769 MB loading renderer peak at modules,
which the 2.086 factor estimates at 1,604 MB. The hosted Linux verdict is
the qualification for MG2.

The first hosted run reached the 241-tick checkpoint and printed a missing
0.1.50 Linux key. Its digest matches the prior engine’s Linux checkpoint
and the freshly recorded 0.1.50 Darwin checkpoint. Record both new keys
for the play-and-resume test. [Hosted checkpoint](https://github.com/project-wildshard/shard-nine-dragon/actions/runs/44578830164/job/135753568893).

The next hosted run downloaded the matching client and timed out waiting for
control after 240 seconds. The Ring 2 probe now reports the last loading
step, error card and failed local asset paths before the published engine
closes the browser. [Hosted timeout](https://github.com/project-wildshard/shard-nine-dragon/actions/runs/44580026170/job/135757843233).

The diagnostic run showed no loading card and no failed local reads.
Explicit SwiftShader boots the exact same product and released client
locally at 625 MB renderer and 1,304 MB phone. Use the engine Ring 1
software renderer on hosted Linux and keep the existing verdict threshold.
[Hosted diagnostic](https://github.com/project-wildshard/shard-nine-dragon/actions/runs/44582526660/job/135766674859).
